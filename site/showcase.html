01 · The Problem

Signature-based IDS cannot catch what it has not already seen.

Traditional intrusion detection systems rely on hand-written rules that match known attack signatures — meaning zero-day and polymorphic attacks slip through. ML-based detectors can generalise, but the field has a trust problem: most models are opaque "black boxes" that security teams cannot audit or justify to an auditor. This project closes that gap.

Solution Architecture

Scapy Live Capture BPF filter · thread-safe queue
↓
Flow Aggregator 5-tuple bidirectional flows
↓
Feature Extractor 84 CIC-IDS2017 statistics
↓
FastAPI · /predict scaler · SelectKBest (84→50)
↓
RF + XGBoost Soft-Voting + SHAP TreeExplainer top-5
↓
Alert · Grafana · SSE Dashboard

Why This Design

  • Decoupled tiers — stateless classifier API is language-agnostic and independently benchmarkable.
  • Tree ensemble — tabular flow features don't need deep learning; trees train faster and admit exact SHAP.
  • Threaded predictions — ThreadPoolExecutor keeps capture running during 10–100 ms API round-trips.
  • SMOTE + class weights — addresses severe class imbalance in CIC-IDS2017.

03 · Key Contributions

What's novel

  • End-to-end pipeline from raw packets to explainable verdict — not just a model on static CSVs.
  • Per-prediction SHAP top-5 attributions make every alert auditable by a human analyst.
  • Production-shaped — rate-limited API, metrics, Grafana dashboard, reproducible Docker stack.

Evaluation rigour

  • Randomised evaluation with 95% CI bounds, not a single lucky split.
  • Live-traffic demo replays CIC-IDS2017 PCAPs against the running API to prove wire-to-alert latency.
  • Confusion matrix & SHAP global importance reported per class — failure modes made visible.
